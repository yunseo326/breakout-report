S8 — 목표가 대신 승률·수익률을 예측하면?

1편(목표가 도달 확률)에서는 예측확률이 높을수록 오히려 나쁜 거래였다. 라벨을 '이겼는지'와 '몇 % 벌었는지'로 바꿔 같은 시간순 검증(2010–2019 학습 · 2020–2021 선택 · 2022–2026 최종)으로 다시 쟀다.

핵심 결론

1라벨을 바꾸니 방향은 정상으로 돌아왔다1편의 '목표가 도달 확률'은 예측이 높을수록 실제 거래가 나빴다(역전). 이번 승률·수익률 모델은 둘 다 예측이 높을수록 실제 성과도 좋다 — 방향 문제는 해결됐다.
2그래도 개별 예측 정확도는 여전히 약하다승률 모델 test AUC 0.538(0.5=동전던지기), 수익률 모델 test R² −0.02(평균만 찍는 것보다 오히려 나쁨). 개별 거래 하나하나의 '몇 % 벌지'는 사실상 못 맞힌다.
3그런데 랭킹으로 쓰면 셋 중 수익률 모델이 확실히 낫다포트폴리오 재생 CAGR(2022–2026): 목표가모델 15%대, 승률모델 24.04%(현행과 비슷), 수익률모델 47.36%(현행 23.29%를 크게 앞섬). 개별 정확도는 약해도 '상대적으로 누가 더 나은가'는 어느 정도 맞힌다는 뜻이다.
4그래도 이미 아는 ATR%순(59.77%)을 못 넘는다수익률모델과 ATR%순을 절반씩 섞어도(51.15%) ATR% 단독보다 못하다. ATR% 비중을 늘릴수록 오히려 더 나빠졌다(33.75%) — 이 테스트 기간(체결 344~352건)의 표본 크기를 감안하면 우연한 잡음일 가능성도 있지만, 적어도 '더 좋아진다'는 근거는 없다.

3. ATR%와 결합하면 더 좋아지는가

수익률모델 랭킹(47.36%)이 ATR%순(59.77%)에 못 미치므로, 둘을 섞으면 더 나은지 같은 test 기간에서 확인했다.

4. 결론

  • 세 모델 다 배포하지 않는다. 어느 것도 이미 검증된 ATR% 랭킹(59.77%)을 넘지 못했다.
  • 그래도 라벨 선택은 중요하다는 걸 확인했다. 같은 특징·같은 방법론인데 라벨만 바꿔서 CAGR이 15%대→24%→47%로 뛰었다. '무엇을 예측할지'가 '어떻게 예측할지'보다 더 큰 영향을 줬다.
  • 수익률 회귀가 가장 유망한 방향이다. 개별 예측력(R²)은 약해도 랭킹 정보는 살아있다. 특징을 더 추가하거나(다중시간대·피봇 등 78개 카탈로그 사후평가에서 다룬 새 변수), 최근 데이터로 재학습 주기를 만들면 개선 여지가 있어 보인다 — 다만 지금 당장 배포할 수준은 아니다.
  • 지금은 ATR% 순위를 계속 쓴다. 세 가지 AI 시도보다 훨씬 간단하고, 훨씬 낫다.
